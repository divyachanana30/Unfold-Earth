#  Unfold Earth
> A responsive travel discovery website designed to inspire exploration and help users discover destinations, experiences, activities, and attractions around the world.

## Overview
Unfold Earth is a responsive travel website created as a team project to provide an engaging and visually rich platform for exploring destinations and travel experiences.
The website brings together destination guides, travel categories, galleries, activities, attractions, travel information, and curated experiences in one platform.
The project focuses on responsive frontend development, structured navigation, visual storytelling, and creating a user-friendly experience across different screen sizes.

## Features
- 🌎 Explore destinations across different continents
- 🏝️ Browse travel categories such as beaches, mountains, wildlife, deserts, waterfalls, volcanoes, and monuments
- 🗺️ Explore destination-specific travel pages
- 🏛️ Discover famous landmarks and the Seven Wonders of the World
- 🖼️ Image and art galleries
- ✈️ Explore travel activities and experiences
- 🚢 Cruise and luxury travel experiences
- 👨‍👩‍👧‍👦 Family travel and adventure sections
- 📖 Travel guides and useful travel information
- ❓ Frequently Asked Questions section
- 📩 Travel enquiry and contact sections
- 📱 Responsive design for different screen sizes
- ✨ Interactive website elements using JavaScript

## Tech Stack
- **HTML5** — Website structure and semantic content
- **CSS3** — Styling, layouts, animations, and responsive design
- **JavaScript** — Interactivity and dynamic frontend behavior

## Project Goals
The main goals of Unfold Earth were to:
- Build a responsive and visually engaging travel platform
- Organize a large amount of destination and travel content
- Create intuitive navigation across multiple pages
- Practice frontend development using HTML, CSS, and JavaScript
- Improve responsive design and user experience
- Collaborate effectively as a team on a web development project

## Team Project
Unfold Earth was developed as a collaborative team project.
Team members contributed to different aspects of the website, including frontend development, page creation, styling, content organization, responsiveness, and interactive functionality.
